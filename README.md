# Loo国生活

按已确认的温馨 3D 卡通视觉原型实现的双人手机网页。Next.js + React + TypeScript；角色使用预生成静态插画，不需要生成式 AI API 或实时 3D 引擎。

## 本地启动

```powershell
npm install
npm run dev
```

打开 http://localhost:3006，选择蓝 Loo 或红 Loo。默认是带示例日记和卡片的本地体验，数据保存在 `.local/home/`，不是浏览器临时存储，刷新和重启后保留。无痕窗口可作为另一方同时登录测试。

需要从同一个 Wi-Fi 的手机体验时，使用这台电脑的局域网 IP 和端口 3006。不要把无口令的本地开发服务暴露到公网。云端启用独立身份口令和数据库。

## 已实现

- 小窝：蓝红身份、六种活动图片、六种独立心情、留言、更新时间、互动收件箱；摸头、抱抱、戳一戳有即时可见反馈，接收方也会看到；页面可见时每 8 秒同步，重新聚焦时立即刷新。
- 大事件：主题插画、心情、文字、单张照片、创建/编辑/删除、未来计划、倒计时置顶、每年重复的纪念日；编辑时检测对方的新修改。
- 照片：浏览器压缩到最长边 1200 像素，服务端限制 2MB 并验证图片签名；照片读取需要登录。
- 卡包：蓝红专属、滑动/按钮切换叠卡、四种预置模板、自定义标题/说明/权益/次数/分钟数/有效期/卡色、使用确认、剩余总时长和兑换历史。
- 菜谱：粘贴小红书链接或分享文案，读取公开标题、描述和结构化菜谱，初步识别菜名/菜系；保存前可以校正。支持手动菜谱、食材/步骤/照片、收藏与搜索、想吃清单上下排序、标记做过、评分和开饭回忆。删除菜谱仍保留做过的历史快照。
- 足迹：Leaflet 在线地图，搜索目的地、地图选点或手填经纬度，多站路线排序，已去过/下一站计划切换；按出发年份回顾地点、国家和估算公里数。与旅行主题大事件双向同步名称、日期、故事和照片，并支持跳转地图查看计划。
- 数据正确性：服务端检查身份、有效期、余额；兑换使用请求 UUID 实现幂等；PostgreSQL 行锁保证并发扣减原子性。本地模式使用进程内写入队列与临时文件替换。
- 手机安全区、320px 至桌面的自适应布局、键盘焦点、对话框焦点约束、减少动画偏好、中文本地字体。

每个生产部署只服务一对情侣，不是多租户公开社交产品。页面关闭时不提供系统推送，未读互动在下次进入时显示。卡券表示双方的约定，不包含支付、购物或实物自动履约。

## 云端部署

沿用本地 Portfolio Manager 项目的 Next.js / Vercel / PostgreSQL 方向。配置步骤见 [docs/deployment.md](docs/deployment.md)。未连接云端账号前，不会存在可供外网访问的正式 URL。

本地模式与正式数据库相互独立；连接空的生产数据库会初始化干净小窝，不会自动上传示例、测试内容或本地私人照片。

## 验证

```powershell
npm run typecheck
npm test
npm run build
npm run test:e2e
```

端到端测试使用已安装的 Microsoft Edge，自动在 3007 端口启动独立测试服务与独立数据目录，生成截图到 `design/qa/`。运行测试时不要同时启动另一个 Next dev 进程；该版本 Next 会限制同一项目同时运行一个开发实例。测试浏览器可在 playwright.config.ts 更改。

## 视觉资源

- `design/v1/`：确认的静态原型和交互规格。
- `public/art/`：6 张运行素材；四张图集提供 12 个角色状态、6 个事件主题与 8 个蓝红卡券插画，另有首页场景及空房间。角色使用透明底 alpha 版本，另保留最初的奶油底原图用于迭代。
- `design/assets-prompts.md`：内置 imagegen 的完整提示词和资产用途。
- `design/transparent-assets-prompts.md`：角色透明底版本的生成提示词。
- `scripts/optimize-art.mjs`：只做 PNG → WebP 压缩，保留透明通道。原始素材保留用于迭代。

图集在页面中用 CSS 背景定位显示，所有文字、表单、票券边框和交互控件都是可操作网页元素。

## 当前边界

动态场景采用独立状态插画叠在小窝背景上；表情细节对应状态插画，独立心情通过气泡和文字表达。没有实时模型或 36 种活动 × 心情组合图片。
本地和浏览器行为可自动验证；真正的 Vercel/Neon 连通、HTTPS 双手机访问需部署凭据后验收。照片以数据库二进制存储，适合小型私人应用；大量原图相册应迁移到对象存储。

小红书识别不需要 AI key，使用公开元数据与菜名/菜系规则生成可编辑草稿，不保证每条笔记可读。遇到登录、验证码或私密笔记时不会绕过限制；保留原链接，允许粘贴分享文案和手动填写。不会凭空生成食材或做法，也不会把远程图片自动下载成私人照片。

地图默认使用 OpenStreetMap 底图和 Nominatim 搜索，需要联网。搜索是点击触发，带 24 小时缓存和全应用限速；云端通过 PostgreSQL 事务锁限制多实例并发。可通过环境变量切换兼容服务。统计只包含已完成旅行，地点按坐标去重；公里数是每段旅行相邻地点的球面直线距离之和，不跨不同旅行连线，不是实际飞行或 GPS 里程。缺少国家代码的地点不计入国家数。

## 双人用卡与时区

卡券由持有人申请，另一方接受。计时卡接受后开始计时，到期扣除一次和对应时长；一次性卡接受即完成；实物卡填写名称、参数、原币种价格、日期和可选照片，再由另一方核对收好。等待和进行中会预留权益，撤回、婉拒或取消不会扣减，历史记录保留。

服务端保存计时截止时刻，打开页面时定期结算；双方关闭网页后，下次打开按原定截止时刻补结算。当前按完整一场扣除固定时长，取消整场不扣，暂不支持暂停或部分分钟结算。

显示时区默认为多伦多，可切换北京或手机本地，偏好只保存在当前设备。共同纪念日、倒计时和卡片有效期始终按小窝的多伦多日历计算。

GitHub 仓库只包含应用代码、运行用 WebP 素材与文档；设计源图和验收截图保留本地。部署配置见 docs/deployment.md。
